## Code Example

Here is a simple example of how to integrate Front's API for ticket creation:

```javascript
const axios = require('axios');

async function createTicket(customerId, message) {
  try {
    const response = await axios.post('https://api.front.com/tickets', {
      customer_id: customerId,
      message: message,
      priority: 'high'
    }, {
      headers: {
        'Authorization': `Bearer ${process.env.FRONT_API_KEY}`,
        'Content-Type': 'application/json'
      }
    });
    console.log('Ticket created:', response.data);
  } catch (error) {
    console.error('Error creating ticket:', error.response.data);
  }
}

createTicket('12345', 'Customer reported an issue with the product.');
```

<Callout kind="info">Always store your API key securely and never expose it in client-side code.</Callout>
